# KuCoin 布局验证

2026-11-23，在 Linux x86_64、Chromium 158、1440 × 900 视口中导入现有 KuCoin 数据。核心、回流、D8 密集批次和全量视图均采集 G6 已绘制的形状。快照使用画布坐标，二次曲线以 0.5 画布单位误差离散。

## 验证结果

四个视图的端口偏离、穿节点、节点碰撞、标签遮挡节点和标签重叠均为零。相同视图的优化前后数据对比保留了节点、边、金额和事件引用。

| 视图 | 节点 / 边 | 交叉数变化 | 共线重叠总长度变化 | 浏览器耗时 |
| --- | --- | --- | --- | --- |
| 核心 | 182 / 285 | 2,563 → 2,830 | 1,591,404 → 511,667 | 641 ms，含导入 |
| 回流 | 5 / 6 | 0 → 0 | 0 → 0 | 86 ms |
| 批次 D8 | 248 / 249 | 10,627 → 12,569 | 5,657,865 → 33,306 | 268 ms |
| 全量 | 1,748 / 2,475 | 583,161 → 975,534 | 6,404,696,239 → 5,380,294,266 | 2,968 ms |

优化前为本次调整通道分配前的画布快照。增加线槽并避开拥挤通道后，多数共线叠压和接触减少，全量视图的交叉数上升。表内长度为按线对累计的画布单位，耗时为本次 Chromium 实测。高密度视图随选择显示交易摘要，常驻标签的检查覆盖回流等更小的视图。

## 复现

合理配置 `KUCOIN_CASE` 和可选的 `KUCOIN_REPORT` 后运行以下命令。测试在 `test-results/` 写出四个 `*.geometry.json` 和核心视图截图。将快照交给布局技能的脚本核查，默认检查端口偏离、穿节点和节点碰撞。

```sh
npm run test:browser -- kucoin.spec.ts
python3 ../AML-Canva/skills/funds-flow-layout/scripts/validate_layout.py \
  test-results/kucoin-*/return.geometry.json --require-rendered \
  --max label_node_overlaps=0 --max label_overlaps=0
```

用同一视图的早期快照作为 `--baseline` 可复查前后业务数据和几何差异。业务图、筛选与展开状态应匹配。完整性能基线和全量交叉优化仍待推进。

## 节点扩宽与密集分列

节点卡改为 320 × 128。自动排版默认行间净距 70、列间净距 340，每列最多 24 个自动放置的节点，每八个预留一行通道。手动固定的节点保留坐标。四个视图的端口偏离、连线穿节点、节点碰撞和标签碰撞均为零。全部 12 个视图的逐笔事件 ID、原始金额及凭证编号均通过对账。

| 视图 | 节点 / 边 | 画布范围 | 交叉数 |
| --- | ---: | ---: | ---: |
| 核心 | 182 / 285 | 13,648 × 4,132 | 5,086 |
| 回流 | 5 / 6 | 2,364 × 326 | 2 |
| 批次 D8 | 248 / 249 | 10,252 × 5,136 | 18,622 |
| 全量 | 1,748 / 2,475 | 60,380 × 5,674 | 621,528 |

分列让高密度视图纵向更紧凑，横向范围随列数增加。核心和 D8 的交叉数较上一次记录有所增加。

## 地址对平行边

同一方向和地址对的聚合边按首笔交易时间及稳定边 ID 排序。共享列间通道的多组地址对分配相邻线槽，间距至少 34 画布单位。在净空足够的正向通道，边从端口平滑分流，经过水平段后再次汇合。受节点阻挡时保留避障通道。点击交易边可在明细中查看完整时间和原始金额。

| KuCoin 视图 | 两个热钱包的入账边 | 有独立水平段与标签 |
| --- | ---: | ---: |
| 核心 | 20 | 20 |
| 全量 | 233 | 233 |

四个验收视图的端口偏离、连线穿节点及标签重叠均为零。全量视图仍有路径穿过其他边标签所在区域，地址对视图可只保留两端之间的交易。浏览器用例验证了逐笔证据一致性、线槽命中及地址对筛选。

### 全量视图的密集通道

上表记录的是全量视图统一使用 34 单位线槽间距时的结果。共享通道超过 32 条平行边时，当前总览改用 7 单位间距，选中边时显示标签。地址对视图恢复 34 单位间距和所有可放置的标签。

KuCoin 全量视图中，两组热钱包入账的 233 条边相对端点的最大纵向绕行从约 3,990 降到 757 画布单位。此前最远的是 `E-1-1-0006`，即热钱包 `0x2b56…8258` 向事件接收地址转入 `364094.35341532 ORN`。浏览器验证该地址对聚焦后仍显示全部 123 条边和标签。
