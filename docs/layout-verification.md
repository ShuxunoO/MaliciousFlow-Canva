# KuCoin 布局验证

2026-11-23，在 Linux x86_64、Chromium 158、1440 × 900 视口中导入现有 KuCoin 数据。核心、回流、D8 密集批次和全量视图均采集 G6 已绘制的形状。快照使用画布坐标，二次曲线以 0.5 画布单位误差离散。

## 验证结果

四个视图的端口偏离、穿节点、节点碰撞、标签遮挡节点和标签重叠均为零。相同视图的优化前后数据对比保留了节点、边、金额和事件引用。

| 视图 | 节点 / 边 | 交叉数变化 | 共线重叠总长度变化 | 浏览器耗时 |
| --- | --- | --- | --- | --- |
| 核心 | 182 / 285 | 2,563 → 2,830 | 1,591,404 → 511,667 | 641 ms，含导入 |
| 回流 | 5 / 6 | 0 → 0 | 0 → 0 | 86 ms |
| 批次 D8 | 248 / 249 | 10,627 → 12,569 | 5,657,865 → 33,306 | 268 ms |
| 全量 | 1,748 / 2,475 | 583,161 → 975,534 | 6,404,696,239 → 5,380,294,266 | 2,968 ms |

优化前为本次调整通道分配前的画布快照。增加线槽并避开拥挤通道后，多数共线叠压和接触减少，全量视图的交叉数上升。表内长度为按线对累计的画布单位，耗时为本次 Chromium 实测。高密度视图随选择显示交易摘要，常驻标签的检查覆盖回流等更小的视图。

## 复现

合理配置 `KUCOIN_CASE` 和可选的 `KUCOIN_REPORT` 后运行以下命令。测试在 `test-results/` 写出四个 `*.geometry.json` 和核心视图截图。将快照交给布局技能的脚本核查，默认检查端口偏离、穿节点和节点碰撞。

```sh
npm run test:browser -- kucoin.spec.ts
python3 ../AML-Canva/skills/funds-flow-layout/scripts/validate_layout.py \
  test-results/kucoin-*/return.geometry.json --require-rendered \
  --max label_node_overlaps=0 --max label_overlaps=0
```

用同一视图的早期快照作为 `--baseline` 可复查前后业务数据和几何差异。业务图、筛选与展开状态应匹配。完整性能基线、旧 AML 画布的跨实现参考和全量交叉优化仍待推进。
